A test before you choose

This kit helps anyone choosing an AI to run on their own computer. You give the models fictional meeting minutes and check whether they get the maintenance date right and recognize that the minutes omit the name of the person who approved it. The comparison brings together 14 variants of local models and points to the standard versions. To repeat the exercise, have a local model already downloaded.

Compare using the same meeting minutes

  1. Open a model you have already downloaded and disconnect from the network. Start a blank conversation with external tools turned off.
  2. Paste the same prompt into each model. Time from submission until the response is complete. If possible, note the memory use right afterward, while the model is still open.
  3. Compare with the answer key. Mark whether the date is correct, the name is omitted, and the response is in Portuguese. If the model fails to load, leave the quality field blank.
