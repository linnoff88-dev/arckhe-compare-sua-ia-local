## Una prueba antes de elegir

Este kit ayuda a quienes están eligiendo una IA para ejecutar en su propio ordenador. Les das a los modelos un acta ficticia y compruebas si aciertan el día del mantenimiento y reconocen que el acta omite el nombre de quien aprobó. La comparación reúne 14 variantes de modelos locales y señala las versiones estándar. Para repetir la práctica, necesitas tener un modelo local ya descargado.

## Compara usando la misma acta

1. Abre un modelo que ya hayas descargado y desconecta la red. Usa una conversación vacía, con las herramientas externas desactivadas.
2. Pega la misma solicitud en cada modelo. Cronometra desde el envío hasta que termine la respuesta. Si puedes, anota la memoria justo después, con el modelo todavía abierto.
3. Compara con la plantilla de respuestas. Marca si el día es correcto, si falta el nombre y si la respuesta está en portugués. Si el modelo falla al cargar, deja la calidad en blanco.
